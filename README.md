# LeetcodeSolutions

My personal collection of **LeetCode solutions** while learning and practicing DSA with Python.

This repository is automatically maintained with [LeetHub v2](https://github.com/arunbhardwaj/LeetHub-2.0).

## Repository Structure

Each solved problem is stored in its own folder using the LeetCode problem number and name:

```text
0258-add-digits/
├── 0258-add-digits.py   # My submitted solution
└── README.md             # Original LeetCode problem
```

So for any problem:

**Problem number → Question → My submitted code**

## Revision Workflow

When revising a problem, I can use the folder to quickly review:

1. The original question and examples.
2. The exact solution I submitted.
3. The approach and logic behind my solution.
4. Time and space complexity.
5. Mistakes or concepts I learned from the problem.

> The problem folders and the **LeetCode Topics** section below are maintained by LeetHub v2.
